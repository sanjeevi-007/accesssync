# ACCESS-EASE (AccessSync)

A browser-based accessibility guidance platform for public libraries.

> **Status:** Under active development. See `docs/PROJECT_BRIEF.md` for full details.

## Quick Start

Setup instructions will be added in Phase 9.

## Tech Stack

- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS
- **Backend:** Python 3.11+, FastAPI, SQLAlchemy 2.x, SQLite
- **Hardware:** ESP32 DevKit V1, RC522 RFID reader, MIFARE cards

## Honest Limits

- The accessibility score is an internal assessment indicator, not a certified rating.
- The website cannot detect real fire alarms or flash physical lights.
- Tactile guidance, signage contrast, and lighting must be assessed by a person.
- Plain HTTP is used for local development. A real deployment should use HTTPS.
